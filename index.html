Weekly publishing checklist
1. Record ESPN's newest standings after Monday Night Football.
2. Confirm all GMs, records, PF and PA.
3. Export current.json.
4. Replace data/current.json in the hosted repository and commit.
5. GitHub Pages or Netlify redeploys automatically.
6. Verify the site shows the new week and odds.
7. Preserve that snapshot in the historical archive.

Future automation options

Recommended: GitHub Pages with GitHub Actions, running Tuesday mornings. For a private ESPN league, an unofficial data endpoint can require ESPN authentication and may change; the included fetch script is optional, requires secure repository secrets, and won't run until team IDs have been mapped. Fallback: supply a Tuesday screenshot, use ChatGPT to transcribe it, and commit the updated JSON. The website itself can remain publicly viewable without exposing ESPN credentials.
